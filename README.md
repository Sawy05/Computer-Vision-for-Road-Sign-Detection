# Road Sign Detection with YOLOv5

Real-time road sign detection using OpenCV and YOLOv5, optimized with TensorRT on Nvidia Jetson Nano.

## Setup
1. Train model using YOLOv5 repo.
2. Convert to TensorRT format.
3. Run `jetson_infer.py` for real-time inference.

## Requirements
- torch
- opencv-python
- tensorrt
